# ManagerQA — Requisitos Iniciais

## Objetivo do MVP

Evoluir o ManagerQA existente mantendo o backend funcional e construir
um frontend novo em React + TypeScript + Mantine.

O foco principal do portfólio é QA Automation.

## Funcionalidades

1. Visualização e gerenciamento dos projetos/sistemas existentes.
2. Cadastro e gerenciamento de módulos.
3. Cadastro e gerenciamento de tecnologias.
4. Gerenciamento de usuários, desenvolvedores e testers.
5. Gerenciamento de demandas.
6. Gerenciamento de casos de teste.
7. Gerenciamento de modelos de teste.
8. Criação de casos de teste a partir de modelos.
9. Planos de teste.
10. Suítes de teste.
11. Execuções de testes.
12. Módulo de regressão.
13. Importação/seleção de demandas aprovadas do Jira para regressão.
14. Integração e rastreabilidade com Jira.
15. Automação Playwright.
16. GitHub Actions.
17. Relatórios e evidências de execução.

## Frontend

O frontend será desenvolvido do zero.

Tecnologias:
- React
- TypeScript
- Vite
- Mantine

O frontend deve consumir a API REST existente.

## Backend

O backend existente será mantido inicialmente.

Não reimplementar o backend sem necessidade.

Alterações serão feitas somente quando necessárias para corrigir,
evoluir ou tornar o sistema mais testável.

## Prioridade

Priorizar funcionalidades que aumentem:
- testabilidade;
- cobertura de QA;
- automação;
- rastreabilidade;
- valor demonstrável em portfólio.

Evitar transformar o projeto em um sistema excessivamente grande.
